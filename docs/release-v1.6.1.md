# v1.6.1-stock • 任务栏盯盘组件

基于上游 [AF Media Bar v1.6.0](https://github.com/Fervent-Tempo/AF-Media-Bar) 的个人二次开发版本，只做了一件事：**在任务栏媒体栏里加了一个股票盯盘组件**。

## 新增：盯盘组件

- 任务栏媒体栏静置层里的一个格子：上行证券简称，下行最新价 + 涨跌幅
- 红涨绿跌（A 股习惯），可切换成绿涨红跌
- 组件只放得下一只股票，按「轮换间隔」在自选列表里轮流显示，**点一下立刻切到下一只**
- 鼠标悬停显示完整读数：名称、价格、涨跌幅、行情时间、第几只/共几只
- **不需要正在播放音乐**：没有媒体时它照样显示
- 交易时段（工作日 9:15–11:35、12:55–15:05）按设置的间隔刷新，收盘后自动降频到 60 秒
- 支持竖向任务栏；与既有组件一样可以拖动排序、在「常驻 / 无媒体」两份布局里单独控制显隐

设置入口：**设置 → 小组件 → 盯盘组件**

| 项 | 默认 | 说明 |
|---|---|---|
| 显示盯盘组件 | 开 | 关闭后组件移除，轮询也停止 |
| 自选股 | `sh000001 sh600519 sz300750` | 空格/逗号分隔；纯数字按首位推断市场 |
| 刷新间隔 | 5 秒 | 2–60 秒 |
| 轮换间隔 | 6 秒 | 2–120 秒 |
| 显示证券简称 / 显示涨跌幅 | 开 | 极窄媒体栏时用 |
| 绿涨红跌 | 关 | 打开后反色 |

数据源：腾讯 `qt.gtimg.cn`（GB18030 报文），无 token、无账号、不写入任何用户数据。

## 安装（覆盖安装）

`AFMediaBar-Setup-v1.6.1-win-x64.exe` 与上游使用**同一个 AppId**，因此可以直接覆盖安装：

1. 先退出正在运行的 AF Media Bar（托盘图标 → 退出）。安装包声明了 `AppMutex`，程序在跑时它会提示先关闭。
2. 双击安装包，装到原目录（`UsePreviousAppDir=yes` 会回到上次的安装路径），设置与自选股保留在 `%LOCALAPPDATA%\AFMediaBar`。
3. 装完进 **设置 → 小组件 → 盯盘组件** 把开关打开一次：旧的 `settings.json` 里没有这个组件的布局项，它会被按"未启用"补齐。

静默安装（与程序内自动更新同一套契约）：

```text
AFMediaBar-Setup-v1.6.1-win-x64.exe /SILENT /SUPPRESSMSGBOXES /NORESTART /CLOSEAPPLICATIONS /AUTORELAUNCH=1 /LANG=chineseschinese
```

卸载走「已安装的应用」里的 `AF Media Bar`，只删程序目录与快捷方式，**不动** `%LOCALAPPDATA%\AFMediaBar` 里的设置。

## 其它

- 上游 main 分支缺 `docs/third-party-audio-notices.md`（csproj 把它作为嵌入资源引用），缺文件时编译报 CS1566，本分支补上了。
- 程序版本号改为 1.6.1：高于上游 1.6.0，因此程序内的更新检查不会把上游版本当成新版本回推。
- 构建环境：.NET 10 SDK（10.0.403）、Inno Setup 6.7.3、Windows 11 (26200) 上编译通过。
